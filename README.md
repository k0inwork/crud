# 📔 Мой Ежедневник (Flask Backend)

Привет! Это простое backend-приложение "Ежедневник", написанное на Python с использованием фреймворка Flask.
Оно умеет работать как через обычные HTML-странички (если открыть в браузере), так и как API (если добавить параметр `?json=1` в конце ссылки).

База данных работает на **PostgreSQL** (я использовал Supabase), но если что, то само приложение создаст локальную `sqlite` базу, если не найдет `.env` файл. Я использую SQLAlchemy для общения с базой.

## 🚀 Фичи:
- **Создание** записи (заголовок, текст)
- **Чтение** списка записей и конкретной записи отдельно
- **Редактирование** записи
- **Удаление** записи
- **Пометка "Выполнено"** (можно зачеркнуть запись, если задача из ежедневника сделана)

## 🛠 Технологии:
- Python 3+
- Flask (фреймворк)
- Flask-SQLAlchemy (ORM для базы данных)
- psycopg2-binary (драйвер для PostgreSQL)
- python-dotenv (чтобы читать настройки из `.env`)
- Jinja2 (HTML-шаблоны)

## 💻 Как запустить у себя:

1. **Склонируй репозиторий:**
   ```bash
   git clone <твой-репозиторий>
   cd <папка-проекта>
   ```

2. **Создай виртуальное окружение (рекомендуется) и активируй его:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/Mac
   venv\Scripts\activate     # Для Windows
   ```

3. **Установи все зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настрой переменные окружения:**
   Создай файл `.env` в корне проекта (там же, где `run.py`) и добавь туда:
   ```env
   DATABASE_URL=postgresql://твой_юзер:твой_пароль@хост_базы:5432/имя_базы
   SECRET_KEY=какой_нибудь_секретный_ключ
   ```
   *Если ты ничего не добавишь, приложение по умолчанию создаст файл `diary.db` (SQLite) прямо в папке.*

5. **Запусти приложение:**
   ```bash
   python run.py
   ```
   Всё! Теперь заходи в браузер по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 📡 API:
Если ты хочешь общаться с сервером через код или Postman (вместо браузера):
- Почти ко всем GET-маршрутам можно добавить `?json=1`, чтобы получить данные в формате JSON.
  - `GET /?json=1` — получить все записи (JSON)
  - `GET /entry/<id>?json=1` — получить одну запись (JSON)
- Если отправлять POST/DELETE запросы с заголовком `Content-Type: application/json` с телом JSON, сервер тоже поймет и ответит JSON-ом.
